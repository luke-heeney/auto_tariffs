# Paper Slides

Beamer seminar deck for `Tariffs, Global Value Chains, and the Incidence of Protection`, using the reproduced paper results as the baseline.

## Build

From the repository root:

```bash
bash paper_slides/code/build_slides.sh
```

The script copies the paper-facing figure assets into `paper_slides/output/assets/` and writes the compiled PDF to:

```text
paper_slides/output/auto_tariffs_seminar.pdf
```

Source lives in `paper_slides/code/auto_tariffs_seminar.tex`.
