# Downstream Replication Workflow

This workflow starts after BLP demand estimation. The estimation pickle is treated
as a fixed input; everything downstream is rebuilt from repo code.

## One-command run

From the repository root:

```bash
bash make.sh
```

The root wrapper runs, in order:

1. `cost_side/make.sh`
2. `post_est/make.sh`
3. `paper/make.sh --skip-render`
4. `python post_est/check_downstream_consistency.py`

`paper/make.sh --skip-render` is intentional in the root workflow. The upstream
tables, cost-side outputs, counterfactuals, rebased bundle, and graph values are
already regenerated by the first two stages.

## Module-level runs

Cost-side only:

```bash
bash cost_side/make.sh
```

Post-estimation only:

```bash
bash post_est/make.sh
```

Paper only:

```bash
bash paper/make.sh
```

Consistency checks only:

```bash
python post_est/check_downstream_consistency.py
```

## Canonical configuration

The canonical downstream path uses:

- `post_est/results_config.json`
- baseline scenario: `no tariff (no subsidy)`
- rebased saved-output bundle selected dynamically from metadata
- fixed upstream BLP result pickle referenced by the config

Alternate configs such as `post_est/results_config_elasticity_interaction.json`
remain robustness or sensitivity paths. They are not run by the one-command
canonical replication wrapper.

## Expected outputs

The main generated outputs are:

- `cost_side/outputs/`
- `cost_side/docs/full_robustness_report.pdf`
- `cost_side/docs/cost_side_robustness_note.pdf`
- `post_est/outputs/`
- `post_est/saved_outputs/<run_id>/`
- `post_est/saved_outputs/<run_id>_rebased_b0/`
- `paper/generated/`
- `paper/build/Auto_Tariffs.reproduced.pdf`
- `paper/build/manifest.json`
- `post_est/outputs/downstream_consistency_report.json`
- `post_est/outputs/downstream_consistency_report.md`

Generated outputs should not be edited by hand.

## Cached external inputs

The cost-side robustness stage needs 2025 exchange-rate values for future-RER
placebo regressions. The one-command workflow uses cached IMF values in
`cost_side/outputs/exchange_rate_2025_backfill_values.csv`, so a replication run
does not depend on live network access. To intentionally refresh the external
data source, run:

```bash
python cost_side/backfill_exchange_rates_2025.py --refresh
```

## Environment knobs

- `PYTHON`: Python executable, default `python`.
- `RSCRIPT`: Rscript executable for cost-side wrappers, default `Rscript`.
- `RESULTS_CONFIG_PATH`: counterfactual config, default
  `post_est/results_config.json`.
- `STRICT_CANONICAL_PDF=1`: makes the root wrapper pass
  `--strict-canonical-pdf` to the paper build.

Changing `RESULTS_CONFIG_PATH` is useful for robustness runs, but the canonical
checker expects `post_est/results_config.json`.
